# UE 5.2 TechArt Toolbox

The updated Unreal Editor Widgets from UE 4.26.

## 1. Vertex Animation Baker
<img width="1016" height="1233" alt="TAT_UE_001" src="https://github.com/user-attachments/assets/75d80324-b77e-4bfc-b551-7d83412c3f6c" />

Sets up and runs Unreal's AnimToTexture plugin for every LOD, in Bone or Vertex mode.
- You pick a skeletal mesh and the animations to bake. There's a seamless-loop option.
It creates:
- one static mesh, one Data Asset and the VAT textures;
- MI_ with all baked parameters filled in, plus a child instance;
